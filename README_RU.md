# NifyGram — стартовый проект

NifyGram — стартовая Flutter-основа мессенджера с Liquid Glass-направлением, светлой/тёмной темой и экраном навигации.

## Что уже заложено
- Flutter-приложение с названием NifyGram.
- Переключение светлой и тёмной темы.
- Liquid Glass-подобные полупрозрачные карточки и плавные переходы.
- Экраны-заготовки: чаты, игры, подарки, профиль и настройки безопасности.
- Конфигурация Firebase вынесена отдельно.
- GitHub Actions workflow для облачной сборки Android APK.

## Важно
Это стартовый интерфейсный проект, а не готовый производственный мессенджер. Реальные аккаунты, отправка сообщений, подтверждение кодом, 2FA, синхронизация, звонки и сквозное шифрование требуют подключения и настройки серверной части. Не вводите реальные пароли/коды в демонстрационные экраны.

## Сборка APK без ПК
1. Создайте репозиторий на GitHub и загрузите туда содержимое архива.
2. Откройте вкладку **Actions** и разрешите запуск workflows.
3. Запустите workflow **Build Android APK** (или сделайте push в `main`).
4. После завершения откройте запуск workflow и скачайте артефакт `nifygram-debug-apk`.
5. Для публикации потребуется отдельная подписанная release-сборка.

## Firebase
Для реальной авторизации создайте проект в Firebase Console, добавьте Android-приложение с package name `com.nifygram.app`, включите Email/Password Authentication и настройте Cloud Firestore. Для Android-файла `google-services.json` используйте конфигурацию своего проекта. В этом архиве секреты и ключи не включены.
