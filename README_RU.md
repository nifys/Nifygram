# NifyGram — стартовый проект

NifyGram — стартовая Flutter-основа мессенджера с Liquid Glass-направлением, светлой/тёмной темой и экраном навигации.

## Что уже заложено
- Flutter-приложение с названием NifyGram.
- Переключение светлой и тёмной темы.
- Liquid Glass-подобные полупрозрачные карточки и плавные переходы.
- Экраны-заготовки: чаты, игры, подарки, профиль и настройки безопасности.
- Конфигурация Firebase вынесена отдельно.
- GitHub Actions workflow для облачной сборки Android APK.

## Важно
Это стартовый интерфейсный проект, а не готовый производственный мессенджер. Реальные аккаунты, отправка сообщений, подтверждение кодом, 2FA, синхронизация, звонки и сквозное шифрование требуют подключения и настройки серверной части. Не вводите реальные пароли/коды в демонстрационные экраны.

## Сборка APK без ПК
1. Создайте репозиторий на GitHub и загрузите туда содержимое архива.
2. Откройте вкладку **Actions** и разрешите запуск workflows.
3. Запустите workflow **Build Android APK** (или сделайте push в `main`).
4. После завершения откройте запуск workflow и скачайте артефакт `nifygram-debug-apk`.
5. Для публикации потребуется отдельная подписанная release-сборка.

## Firebase
Для реальной авторизации создайте проект в Firebase Console, добавьте Android-приложение с package name `com.nifygram.app`, включите Email/Password Authentication и настройте Cloud Firestore. Для Android-файла `google-services.json` используйте конфигурацию своего проекта. В этом архиве секреты и ключи не включены.

## Supabase: начальная серверная основа

В проект добавлены `supabase/migrations/0001_nifygram_schema.sql`,
`lib/config/supabase_config.dart` и `lib/services/nifygram_backend.dart`.
Это стартовая интеграция, а не завершённый мессенджер.

1. Создай проект в Supabase.
2. Открой SQL Editor и выполни SQL из `supabase/migrations/0001_nifygram_schema.sql`.
3. В Authentication настрой подтверждение email и redirect URL под своё приложение.
4. Добавь в `lib/main.dart` инициализацию Supabase до `runApp` (или попроси меня подключить её следующим шагом):
   `await NifygramBackend.initialize(SupabaseConfig.url, SupabaseConfig.anonKey);`
5. Запускай сборку, передав публичные параметры проекта:
   `flutter build apk --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co --dart-define=SUPABASE_ANON_KEY=YOUR_ANON_KEY`

Важно:
- Используй только publishable/anon key в мобильном приложении. Никогда не добавляй `service_role` key в APK или GitHub.
- Админ-действия (галочки, баны, выдача монет/NFT, Premium) должны выполняться через защищённые Supabase Edge Functions с проверкой серверной роли. Не выдавай себе роль администратора через клиент.
- SQL задаёт базовую модель и RLS, но до публичного запуска нужно протестировать политики и добавить Edge Functions для покупок, торговли и модерации.
- Бонус 15 Fufcoin сейчас предусмотрен триггером регистрации; тестируй в отдельном проекте и проверь ledger, прежде чем запускать для реальных пользователей.
- Premium в 10 ₽ не подтверждается автоматически: сначала требуется проверка оплаты администратором.
- Для настоящего end-to-end шифрования нельзя просто сохранить обычный текст в `messages.body`; нужен отдельный криптографический протокол и управление ключами.
